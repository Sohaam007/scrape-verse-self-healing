# 🕸️ Scrape-Verse: Self-Healing Web Scraper

![WeMakeDevs](https://img.shields.io/badge/Hackathon-WeMakeDevs%20Scrape--Verse-blueviolet?style=for-the-badge)
![Bright Data](https://img.shields.io/badge/Powered%20By-Bright%20Data-blue?style=for-the-badge)
![UI](https://img.shields.io/badge/Frontend-HTML%20%7C%20CSS-orange?style=for-the-badge)

An autonomous, self-healing data extraction pipeline built for the **WeMakeDevs Scrape-Verse Hackathon**. This project solves one of the biggest headaches in web scraping: broken CSS selectors. Using the Bright Data CLI, the scraper automatically detects website structural changes and heals the extraction pipeline on the fly without any manual recoding.

The extracted data is presented in a custom, polished receipt-style frontend interface featuring live filtering and data visualization.

## ✨ Features

- **🤖 AI-Powered Self-Healing:** Simulates website failure by sabotaging CSS selectors. The Bright Data CLI detects the breakage and automatically heals the pipeline to ensure continuous data extraction.
- **📚 Target Catalog:** Successfully extracts complex book catalog data seamlessly, even when the underlying DOM structure changes.
- **🧾 Receipt-Style UI:** A clean, modern HTML/CSS frontend index that displays the scraped data in an aesthetic receipt format.
- **🔍 Live Filtering & Visualization:** Easily sort, filter, and visualize the extracted dataset directly from the frontend interface.

## 🛠️ Tech Stack

- **Data Extraction:** Bright Data CLI
- **Frontend UI:** HTML5, CSS3 (Custom Receipt-Style Design)
- **Data Handling:** JSON / DOM Parsing
- **Version Control:** Git & GitHub
